Third Party Test App

External Notification Playground

This isolated web app behaves like a separate product. It stores candidate test data locally, accepts your orchestration credentials, and sends message content through your existing integration API.

How it works

  1. Fill API settings and auth.
  2. Add one or more test candidates.
  3. Select one, many, or all candidates, then send the message through the orchestration endpoint.
